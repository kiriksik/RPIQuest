# Запуск

1. Перейти в корень проекта
2. Запустить python3 -m main
3. Сервер должен быть включен (server_mock.py)

# Переменные
1. Переменные - config.py
2. Инициализация в gui.py (GPIO и Адрес сервера)
3. Цвета стилей - styles.py

Размер экрана адаптивный. Скорость движения воды тоже. Переменные в config.py
